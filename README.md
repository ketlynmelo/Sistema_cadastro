Sistema de Gerenciamento de Pratos de Restaurante

Este projeto foi desenvolvido com o objetivo de facilitar o controle dos pratos cadastrados em um restaurante. Atualmente, o restaurante não possui um sistema centralizado para armazenar essas informações, o que dificulta saber quais pratos já foram cadastrados e quem realizou cada cadastro.Para resolver esse problema, foi criado um sistema utilizando PHP, MySQL, HTML e CSS, executado no XAMPP. A aplicação permite cadastrar usuários e gerenciar pratos, mantendo o vínculo entre cada prato e o colaborador responsável pelo seu registro.

Tecnologias Utilizadas
PHP
MySQL
HTML5
CSS3
XAMPP
